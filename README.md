# Framework de Automatización de Pruebas - SauceDemo

Framework de testing automatizado desarrollado en Python, que combina pruebas de UI con Selenium WebDriver y pruebas de API con Requests, aplicando el patrón Page Object Model y generando reportes HTML detallados.

---

## Tecnologías Utilizadas

- **Python 3.10+**
- **Pytest** — framework de testing
- **Selenium WebDriver** — automatización de UI
- **Requests** — pruebas de API
- **pytest-html** — generación de reportes HTML
- **webdriver-manager** — gestión automática de ChromeDriver
- **Git / GitHub** — control de versiones
